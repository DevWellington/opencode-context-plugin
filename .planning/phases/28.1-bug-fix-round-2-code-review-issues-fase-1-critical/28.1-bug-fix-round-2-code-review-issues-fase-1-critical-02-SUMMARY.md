# Phase 28.1 Plan 02: CACHE_DIR project-relative path fix Summary

**Replaced hardcoded CWD-relative .opencode/context-session paths with baseDir-parameterized path resolution across contextCache.js, contextInjector.js, and all callers**

## Performance

- **Duration:** 4 min
- **Started:** 2026-05-24T18:51:10Z
- **Completed:** 2026-05-24T18:52:02Z
- **Tasks:** 3
- **Files modified:** 6

## Accomplishments
- Removed hardcoded `CACHE_DIR` constant in `contextCache.js` — replaced with `getCacheDir(baseDir)` helper
- Removed hardcoded `CONTEXT_SESSION_DIR` constant in `contextInjector.js` — replaced with `getContextDir(baseDir)` helper
- All 5 exported contextCache functions (`getCachedContexts`, `getCachedContext`, `isCacheValid`, `saveToCache`, `invalidateCache`, `getCacheStats`) now accept `baseDir` as their last parameter
- `getRelevantContexts` in contextInjector.js extracts `baseDir` from `options` (defaults to `process.cwd()`)
- `injectContextPrompt` in contextInjector.js accepts `(currentSession, baseDir = process.cwd())`
- Updated all callers: `saveContext.js` passes `directory` to `invalidateCache`; `injectPrompt.js` forwards `baseDir`; `cli/inject.js` passes `baseDir: directory`; `index.js` passes `this.directory` / `session.directory`

## Files Created/Modified
- `src/modules/contextCache.js` - Removed CACHE_DIR, added `getCacheDir(baseDir)`, all exports accept baseDir
- `src/modules/contextInjector.js` - Removed CONTEXT_SESSION_DIR, added `getContextDir(baseDir)`, baseDir from options
- `src/modules/saveContext.js` - `invalidateCache(directory)` with project directory

## Decisions Made
- `baseDir` is always the last parameter for consistency (except `getRelevantContexts` which reads it from options object)
- Backward compatibility maintained via `process.cwd()` default — callers that don't pass baseDir continue to work with CWD resolution
- Helper functions (`getCacheDir`, `getContextDir`) centralize the path construction pattern
