## Decisions Made
- `saveState()` itself is NOT modified — it still throws to allow direct callers to handle conflicts their own way
- `loadState()` calls remain unwrapped — disk read errors (corrupted state file, permission errors) should still propagate
- In-memory state mutations before saveState (e.g., `state.lastSummarized[key] = ...`) are not rolled back on failure — harmless because the next call will reload fresh state from disk
- Each catch uses the existing `logger` function (no console.error added)
